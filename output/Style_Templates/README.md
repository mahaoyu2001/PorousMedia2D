# Standalone figure templates

These 86 FIG files supply original graphical settings and FEM graphics.
Analytical curves inside a template can be outdated: round-2 routines replace
their data before exporting revised figures. Use `cal_stress_statistics.m`
as the numerical source. Updated skewness axes use [-1.5, 1.5].

Companion PNGs supply the original pixel dimensions checked by the export routine.
